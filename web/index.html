KEY FEATURES

교육생 시점에서 겪은 삽질을 한 방에 해결

수업 첫날부터 환경 설정 에러 때문에 진 빠지지 않도록, 직접 겪어보고 다듬은 맞춤 기능들입니다.

Git for Windows 전역 설정

Windows용 최신 Git을 무인 설치하고 Git Credential Manager와 시스템 PATH를 자동 등록하여 새 터미널 어디서든 즉시 git 명령어를 사용할 수 있습니다.

창 꺼짐 없는 WSL2 & Ubuntu

클릭 즉시 닫히던 기존 바로가기 문제 해결! Keep-Alive 래퍼를 적용하여 리눅스 사용자 홈(~)으로 바로 연결되는 전용 바탕화면 아이콘을 생성합니다.

Docker Desktop & WSL 통합 자동화

최신 Docker Desktop 설정(settings-store.json)을 자동 튜닝하여 WSL Ubuntu 연동 스위치를 사전에 켜두고, 리눅스 docker 그룹 권한까지 자동 등록합니다.

Python 3.12 전역 환경변수

WindowsApps Store 가짜 스텁을 무력화하고 전역 시스템 PATH에 등록하여 새 CMD나 PowerShell 어디서든 즉시 python 및 pip 명령을 실행할 수 있습니다.

VS Code 한국어 & 필수 확장팩 자동 구성

공식 한국어 언어팩과 WSL Remote, Python, GitLens, GitHub 확장을 무인 설치하고 argv.json 로케일 주입 및 바로가기(--locale=ko)까지 구성하여 더블클릭 즉시 100% 한글로 시작됩니다.

리눅스 개발 도구 & 계정 무인 세팅

비밀번호 입력 창에서 멈추지 않도록 전용 개발자 계정(developer / 1234)과 무비밀번호 sudo를 자동 프로비저닝하고 build-essential, git, venv, ruff를 일괄 설치합니다.

초고속 공식 엔진 & 초코레이틀리

제조사 공식 CDN을 통한 초고속 무인 다운로드로 방화벽/보안 정책 오류를 방지하며, 필요 시 메뉴에서 Chocolatey 패키지 매니저를 선택 설치할 수 있습니다.

Discord 데스크톱 앱 자동 설치

부트캠프/교육 과정의 실시간 소통, 과제 질문, 팀 프로젝트를 위한 Discord 공식 앱을 무인 설치하고 바탕화면 바로가기를 자동 생성합니다.

Active Directory(AD 도메인) 완벽 지원

실습실 공용 PC의 AD 도메인 계정 로그인 시 발생하는 Docker 권한(docker-users 그룹 자동 매핑)을 완벽 해결하고, C:\Users\Default 템플릿과 머신 전역 safe.directory "*" 정책으로 모든 학생에게 최적의 환경을 보장합니다.

인텔 울트라 9 & RTX 5060 & 32GB RAM 최적화

32GB RAM 시스템 맞춤 WSL2 가상머신 리소스 최적화(.wslconfig 메모리 24GB, 24코어 할당, autoMemoryReclaim) 및 NVIDIA GeForce RTX 5060 WSL2 CUDA GPU 가속을 자동 연동합니다.

HOW TO USE

단 4단계로 끝나는 개발 환경 세팅

1

OnePunch.exe 다운로드

상단의 다운로드 버튼을 클릭하거나 USB로 받아서 개인 PC 또는 교육장 PC에 저장합니다. (용량: 약 77KB)

2

관리자 권한으로 실행

프로그램을 더블 클릭합니다. UAC(사용자 계정 컨트롤) 승인 창이 뜨면 '예'를 눌러 관리자 권한을 승인합니다.

3

메뉴에서 [1] 입력 후 엔터

콘솔 메뉴에서 1을 입력하고 엔터를 누르면 모든 도구가 자동으로 무인 설치됩니다. 이미 설치되어 있는 도구는 4단계 심층 감지로 건너뛰므로 안심하세요!

4

PC 재부팅 시 OnePunch 실행창 꼭 [예/실행] 클릭!

1단계 설치 완료 후 재부팅하면 OnePunch 실행 확인창(UAC 관리자 확인)이 자동으로 뜹니다. 이때 반드시 [예] 또는 [실행]을 눌러주셔야 2단계(WSL 리눅스 도구 구성 및 Docker WSL2 자동 연동)가 100% 마무리됩니다!

브라우저 보안 알림 안심 가이드

"의심스러운 파일" 경고가 뜨나요? 100% 안전합니다!

원펀치(OnePunch.exe)는 동기들을 위해 직접 빌드한 오픈소스 순수 C# 경량 유틸리티입니다.
수백만 원에 달하는 기업용 유료 코드서명(EV Code Signing) 인증서가 아직 등록되지 않은 신규 배포 파일이라 브라우저와 윈도우가 "신뢰도가 아직 검증되지 않은 파일"이라며 주의를 주는 정상적인 현상입니다. 바이러스나 광고가 전혀 없으니 안심하세요! 😊

Google Chrome (크롬)

의심스러운 파일 다운로드 해제 4단계

  1. 1

    다운로드 차단 알림 확인

    화면 우측 상단 다운로드 아이콘에 "의심스러운 파일이 차단되었습니다" 알림이 뜹니다.

  2. 2

    다운로드 목록 열기

    우측 상단 다운로드 아이콘 클릭 또는 단축키 Ctrl + J를 누릅니다.

  3. 3

    [의심스러운 파일 다운로드] 클릭

    차단된 항목 아래에 있는 [의심스러운 파일 다운로드](또는 [계속 다운로드])를 클릭합니다.

  4. 4

    팝업에서 [계속 다운로드] 완료

    "그래도 계속 다운로드하시겠습니까?" 팝업에서 [계속 다운로드]를 누르면 다운로드가 완료됩니다!

Microsoft Edge (엣지)

SmartScreen 다운로드 유지 4단계

  1. 1

    다운로드 목록 경고 확인

    우측 상단 다운로드 목록에 "OnePunch.exe은(는) 일반적으로 다운로드되지 않으며..." 문구가 뜹니다.

  2. 2

    마우스 올리고 [ ... ] 버튼 클릭

    해당 항목에 마우스를 올린 뒤 나타나는 [...] (추가 작업) 아이콘을 클릭합니다.

  3. 3

    메뉴에서 [유지] (Keep) 선택

    나타나는 옵션 메뉴에서 [유지](또는 Keep)를 선택합니다.

  4. 4

    [자세히 보기] > [그래도 계속] 클릭

    안내 창 하단의 [자세히 보기]를 누른 후 [그래도 계속]을 누르면 다운로드가 완료됩니다!

실행 시 파란색 "Windows의 PC 보호" 창이 뜰 때

화면 본문의 파란색 밑줄 [추가 정보] 링크를 클릭한 후, 우측 하단에 생기는 [실행] 버튼을 누르면 정상적으로 시작됩니다.

FAQ

자주 묻는 질문

Q. 다운로드할 때 '의심스러운 파일'이나 '인식할 수 없는 앱'이라고 뜨는데 안전한가요?

100% 안전합니다! 이상한 프로그램이나 바이러스가 전혀 아닙니다.
원펀치는 교육생 동기들을 위해 직접 개발한 순수 오픈소스 C# 도구입니다. 수백만 원에 달하는 대기업용 유료 코드서명(EV Code Signing) 인증서가 아직 등록되지 않은 신규 .exe 파일은 크롬/엣지 및 윈도우 SmartScreen이 기본 정책상 "알려지지 않은 파일"이라며 주의 경고를 띄웁니다. 크롬에서는 [의심스러운 파일 다운로드 > 계속], 엣지에서는 [... > 유지 > 자세히 보기 > 그래도 계속]을 누르시면 정상 다운로드됩니다.

Q. 이미 파이썬이나 VS Code가 설치되어 있는 PC는 어떻게 되나요?

원펀치는 4단계 심층 감지 엔진을 내장하고 있어 기존 설치 여부와 버전을 정확히 파악합니다. 이미 올바르게 설치된 프로그램은 중복 설치하지 않고 건너뛰며, 누락된 환경변수(PATH)와 한국어 언어팩 등 부족한 부분만 똑똑하게 보완합니다.

Q. 실습실 PC에 인터넷이 느리거나 패키지 매니저가 안 깔려 있으면요?

원펀치는 공식 CDN 인스톨러 직접 다운로드 엔진을 기본으로 사용하여 별도 외부 런타임 없이 초고속으로 설치됩니다. 혹시 모를 경우를 위해 초코레이틀리(Chocolatey) 패키지 매니저 개별 설치 메뉴도 지원합니다.

Q. VS Code 한국어 언어팩과 필수 확장팩들은 어떻게 적용되나요?

원펀치가 공식 한국어 언어팩과 함께 WSL Remote, Python, GitLens, GitHub 확장을 일괄 설치합니다. 또한 argv.json 런타임 인자 주입 및 바로가기에 --locale=ko를 자동 연결하여, 바탕화면이나 시작 메뉴에서 실행 즉시 100% 한글 화면으로 열립니다.

Q. Docker Desktop과 WSL2 연동은 어떻게 동작하나요?

원펀치가 최신 Docker Desktop 설정 저장소(settings-store.json)에 Ubuntu-24.04 연동 스위치를 사전에 켜두며, 리눅스 내부 docker 소켓 그룹 권한까지 자동 등록합니다. 시스템 트레이에 고래 아이콘이 뜬 후 WSL 터미널에서 즉시 docker ps를 실행하실 수 있습니다.

Q. WSL 바탕화면 바로가기를 누르면 왜 창이 안 꺼지나요?

기존 WSL 단축 아이콘은 초기 설정 미완료 시 즉시 닫혀버리는 문제가 있었습니다. 원펀치는 안전한 Keep-Alive 래퍼를 적용하여 리눅스 계정의 홈 디렉터리(~)로 바로 진입하며, 오류가 나더라도 에러 메시지를 확인할 수 있도록 창이 유지됩니다.
